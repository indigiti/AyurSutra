# Classical reader and authorized editorial imports

The shared reader applies to Sushruta Samhita, Charaka Samhita, Ashtanga Hridaya, Ashtanga Sangraha and Madhava Nidana. Alternate script views are display transliterations, not translations or separately proofread editions. Unsupported characters are retained. Tamil uses a superscripted Sanskrit convention. The original source is not rewritten.

Both the offline Ayana migration and the administrative chapter JSON upload accept optional `title_devanagari` and `title_iast` fields. Each passage can include `adhikarana`, `commentary_sanskrit` (either Devanagari or IAST), `commentary_en` and `key_terms[].iast`. The existing `commentary` field is legacy editorial text and is not assumed to be Sanskrit. A commentary-only entry needs a reference and original Sanskrit commentary, but no base verse. For a combined śloka card, provide the verified range as its reference and the original text in source order. Never infer editorial groupings by array position.

Only import content you are authorized to republish, with its source URL and independently reconciled chapter and passage boundaries. The public reader only uses published editorial records or the attributed source corpus. No Ayana commentary, glossary or audio is shipped by these changes.
